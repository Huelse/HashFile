# HashFile 文件哈希计算

在 fnOS 中计算文件或目录内的 SHA-256/SHA-512/SHA-1/MD5/BLAKE3 哈希值，支持批量处理与校验比对

## 说明

* 点击路径输入框左侧的**选择**按钮即可直接挑选文件或目录，系统会自动把它授权给本应用
  （需系统 ≥ 1.2.0401、App ≥ 1.34.0；版本较低或在独立浏览器窗口中打开时该按钮不显示）
* 也可以用`文件右键-详细信息-复制原始路径`，粘贴到路径输入框内计算
* 已授权的目录可在界面右上角的**已授权目录**里查看和删除
* 如提示无权限，请先在应用设置内添加文件夹**只读**权限
* `app/ui/config` 中添加 fileTypes 可右键打开方式并计算文件哈希值，例如：`"fileTypes": ["mp4", "mkv", "avi", "zip", "rar", "7z"]`
